#### PROFESSIONAL SELF-ASSESSMENT
Working through the Computer Science program at SNHU has made me develop a lot of skills, knowledge, and professionalism in how I conduct myself and my work. My understanding of computer science had basically just started when I went into this program and since I've not only developed my skills relating to this course massively, but I've also developed my personal skills in how to interact with others in a collaborative manner and how to develop professionally. Working in discussion posts has given me a new way of looking at collaborating with others through discussion, even if the post wasn't something I completely agreed with it would still give me new perspective that I wouldn't have rationalized otherwise. Having other eyes on my work has also developed my in receiving feedback, much of my advancement has come from others pointing out ways I could get better through an objective look at my work from a third-party. This has helped me gain insight into the collaborative process as well as the development process by taking these discussions as a way to improve my work outside of my personal skill. Working on the rubrics throughout this course has given me an idea on what expectation looks like, having that requirement gave me a better understanding of where to go with my work than if I were to come up with a goal myself. This expectation can put pressure on some, but for me it gave me a sense of comfort knowing where I'd want to take my work and how a finalized idea would look like. This has aided in my ability to communicate with stakeholders as it guides me on how to interact with requirements and expectations rather than becoming stressed with what's expected of me. Classes like Client-server Development has helped me develop my understanding of data structures and algorithms and how these concepts exist behind the scenes of an application. Knowing how to make a search function or a filter options, even at a basic level, has given me a better understanding on how I interact with those functions in the regular internet and why they work they way they do. Learning more about algorithms through my Current Emerging Trends class has also developed my understanding on how an algorithm can evolve and function through data collection giving me a better idea on search or feed algorithms. In the Software Development Lifecycle class I got an entire new look at how software development progresses at a professional level and it gave me a lot of insight into common practices and strategies through the cycle. Understanding each role, learning how they interact with each other, conduct meetings, and continue to grow their project was eye-opening in how development cycles go. Security has been a constant throughout this program as each class highlighted the importance of secure coding and how vulnerabilities can occur if left unnoticed. Taking this course has completely changed how I approach a security mindset both in Computer Science and my own personal security online. Understanding and reacting to security risk is an important aspect of computer science that I've continued to grow with each course and each project I work on.

With this E-portfolio I'm presenting my finalized capstone project for the Gravioso Salvare Dashboard that I made in Client-Server Development. Each directory contains an enhancement over the original project that increases functionality, employs a security mindset, follows professional standard coding and commenting, and delivers an expanded version of my prior project. I chose this project due to its capabilities of being enhanced in every category while following course outcomes. Enhancements follow software design and engineering, Algorithms and data structures, and databases that all can be applied to the initial artifact. My first enhancement focuses on my ability to transfer from one coding language to another while still following initial goals and expanding on future functionality. This showcases my experience with both programming languages and how I can create an application showing best practices from either language. My second enhancement focuses on creating a sort and search functionality to the application to allow users easier methods in finding their chosen animal. Creating these algorithms showcase my understanding to develop quality algorithmic functionality with best practices and how that can further develop an application's functionality and use. My third and final enhancement focuses on implementing MySQL and CRUD implementation into the project to develop a security mindset which was lacking from the initial artifact. MySQL could act as a way to prevent public interference with administrative privilege of the application by making login information private to only administrators. This creates a level of privilege between guest accounts and administrator accounts, this is to prevent guests from tampering with the database when administrators should only be capable to update the database to real-life consistency. This showcases my development with security and how to incorporate it into my future projects while CRUD implementation offers database management to those with privileged access. This project showcases the development I've gone through in this program and how I plan to continue developing as I make a professional career into Computer Science.
